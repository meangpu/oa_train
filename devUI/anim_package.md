## Optional: animations

ถ้าต้องการ animation ติดตั้ง package เพิ่มคือ

## tailwind animate

อ่านนี่> https://www.npmjs.com/package/tailwindcss-animate
ติดตั้งยากกว่าหน่อย คือ npm เสร็จต้องสร้างไฟล์ config มาเพิ่มอีก `tailwind.config.js`

```sh
npm i tailwindcss-animate
```

และเลิก comment `@plugin "tailwindcss-animate";` ใน `index.css`
